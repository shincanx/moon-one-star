The funniest one-star review of the Moon in 103 characters: it ghosts us for two weeks every month, comes back half-dressed, and calls it a phase.

> One star. Disappears for two weeks every month, comes back half-dressed, and calls it a phase. Grow up.

`main.py` is deterministic, uses no network and no dependencies. It writes that one line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, else `/output`).
